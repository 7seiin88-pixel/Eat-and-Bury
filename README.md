# حفر ودفن – نسخة الأونلاين

## الملفات
- `server.js` : السيرفر (يربط اللاعبين ببعض في غرف، ويوصل المايك).
- `package.json` : إعدادات تشغيل السيرفر.
- `public/index.html` : اللعبة نفسها (لازم تكون داخل مجلد public).

ما يحتاج تثبيت أي مكتبات، يكفي Node.js نسخة 18 أو أحدث.

## التشغيل على Render
1. سوّ حساب في https://github.com وارفع هالمجلد كمستودع جديد (Repository).
2. سوّ حساب في https://render.com وسجّل دخول بحساب GitHub.
3. اضغط New ثم Web Service، واختر المستودع.
4. الإعدادات:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: Starter ($7 بالشهر، ما يطفي) أو Free للتجربة
5. اضغط Create Web Service وانتظر دقيقتين.
6. يطلع لك رابط مثل `https://eat-and-bury.onrender.com` افتحه وابدأ.

ملاحظة: النسخة المجانية في Render تنام إذا ما أحد استخدمها 15 دقيقة. نوع Starter يبقى شغال على طول.

## طريقة اللعب أونلاين
1. افتح الرابط واضغط "العب أونلاين مع ربعك" واكتب اسمك وسوّ غرفة.
2. أرسل رابط الغرفة لربعك (فيه زر واتساب).
3. المقعد 1 و3 فريق، و2 و4 فريق. المضيف يقدر يغيّر أماكن اللاعبين بزر ⇅.
4. المقاعد الفاضية يلعبها الكمبيوتر.
5. المضيف يختار الإعدادات ويوزّع الأوراق.
6. زر المايك يفتح ويقفل الصوت.
7. أي أحد يدخل الرابط بعد ما تبدأ اللعبة (أو المقاعد مليانة) يدخل متفرج، وعدد المتفرجين يطلع فوق بعلامة 👁.
8. تقدر تكتم أي لاعب من صورته: ما تشوف رسايله ولا تسمع صوته ولا توصلك هداياه.

## ملاحظات مهمة
- لازم الرابط يكون https (Render يسويها تلقائياً) عشان المايك يشتغل.
- تقدر تطلع من الصفحة (واتساب، مكالمة، قفل الشاشة) والغرفة تنتظرك ٣ دقايق وترجعك تلقائياً.
- إذا لاعب طلع، الكمبيوتر يكمل مكانه.
- المايك يشتغل لاعب لاعب مباشرة. بعض شبكات الجوال (4G/5G) تمنع هذا النوع من الاتصال، وقتها نحتاج نضيف خادم TURN (فيه خدمات مجانية أو رخيصة) في الخطوة الجاية.
